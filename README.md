# Лабораторна робота № 1

Розгортання середовища автоматизації тестування. Структура проєкту та перший автоматизований тест.

**Дисципліна:** Автоматизація тестування  
**Спеціальність:** F2 «Інженерія програмного забезпечення»  
**Виконавець:** Легета Василина  
**Група:** 2  
**Варіант:** 1. Перетворення кілометрів на милі та назад; відхилення від’ємних значень.

## Мета

Розгорнути робоче середовище для автоматизації тестування на базі Node.js і TypeScript, налаштувати засоби контролю якості коду, розробити та запустити автоматизовані тести модуля перетворення відстані.

## Встановлення

Потрібні Node.js `v20.19` або новіша (для гілки 22 — від `v22.13`), npm і Git.

```bash
git clone https://github.com/lehetavasylyna/qa-automation
cd qa-automation
npm install
```

Команда `npm install` відтворює залежності з `package-lock.json`. Каталог `node_modules` у репозиторій не входить.

## Запуск

```bash
npm test            # одноразовий прогін тестів
npm run test:watch  # перезапуск після зміни файлів
npm run coverage    # прогін і звіт покриття (текст і coverage/index.html)
npm run lint        # статичний аналіз ESLint
npm run format      # форматування коду Prettier
```

## Структура проєкту

```text
qa-automation/
├── src/
│   └── distance.ts          # модуль варіанта 1: км ↔ милі
├── tests/
│   └── distance.test.ts     # тести модуля
├── .gitignore               # виключення node_modules, coverage, dist
├── .prettierrc              # правила форматування
├── eslint.config.mjs        # правила лінтера
├── package.json             # залежності та команди scripts
├── package-lock.json        # зафіксовані версії залежностей
├── tsconfig.json            # налаштування TypeScript
├── vitest.config.ts         # раннер тестів і пороги покриття
└── README.md
```

| Файл                     | Призначення                                                                                                                       |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `src/distance.ts`        | `kilometersToMiles` і `milesToKilometers`. 1 миля = 1,609344 км. Від’ємні та нечислові значення дають помилку `INVALID_DISTANCE`. |
| `tests/distance.test.ts` | Коректні перетворення в обидва боки, межа 0, від’ємні значення та `NaN`.                                                          |
| `vitest.config.ts`       | Середовище `node`, пошук `tests/**/*.test.ts`, покриття v8 лише для `src/**/*.ts`, пороги lines 80, branches 80, functions 100.   |
| `tsconfig.json`          | Компіляція ES2022 із увімкненим `strict`.                                                                                         |
| `eslint.config.mjs`      | Рекомендовані правила JavaScript і TypeScript; невикористані змінні — помилка.                                                    |
| `.prettierrc`            | Крапка з комою, одинарні лапки, ширина рядка 80.                                                                                  |
| `package.json`           | Скрипти `test`, `test:watch`, `coverage`, `lint`, `format`. Залежності тестування стоять у `devDependencies`.                     |
| `.gitignore`             | Не дає потрапити в репозиторій `node_modules/`, `coverage/`, `dist/`.                                                             |

## Індивідуальне завдання

Модуль покритий тестами на коректні дані, межове значення 0 і некоректні дані з винятком. Прогін `npm run coverage` досягає заданих порогів. Прогін `npm run lint` завершується без помилок.
